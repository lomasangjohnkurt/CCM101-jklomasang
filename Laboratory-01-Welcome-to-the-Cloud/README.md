# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity introduced the basic environment and tools
used by cloud computing professionals. The activity involved using
KillerCoda to access a Linux environment and GitHub to create a
cloud computing portfolio.

## Objectives 
Upon successful completion of this mission, you should be able to: 
 Access a cloud-based Linux environment using KillerCoda.  
 Explore and navigate the Linux operating system.  
 Gather basic system information.  
 Organize files and directories using Linux commands.  
 Create and maintain a professional GitHub repository.  
 Document technical work using Markdown.  
 Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed
1. Accessed the Ubuntu Linux environment using KillerCoda.
2. Created a new Linux user.
3. Checked the username, working directory, and hostname.
4. Gathered Linux system information.
5. Created directories and Markdown files.
6. Created a GitHub repository.
7. Organized laboratory documentation and screenshots.
