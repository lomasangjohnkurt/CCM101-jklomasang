# Reflection

This laboratory activity helped me understand the basic working
environment used in cloud computing. I learned how to access a Linux
environment through KillerCoda, create a user account, navigate the
Linux file system and collect system information.

The activity gave me a basic foundation in Linux and cloud
computing tools that I can use in the succeeding laboratory activities and also
I learned the importance of organizing technical documentation
and maintaining a GitHub repository. These skills are useful because
cloud engineers need to manage systems while properly documenting
their work.
