# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, Artificial Intelligence, Machine Learning, data analytics and application development. 

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of Regions and Zones. A Region is a geographic area where Google Cloud resources can be deployed, while Zones are locations within a Region that provide cloud resources.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and manage virtual machines, storage, networks, databases, Kubernetes clusters, and other resources through the console.

## Four Core Services

### 1. Google Compute Engine

Google Compute Engine provides virtual machines that run on Google's infrastructure. Organizations can use these virtual machines to host applications and other computing workloads.

### 2. Google Cloud Storage

Google Cloud Storage is an object storage service used to store files and other types of data. It can be used for backups, application data, media files and large datasets.

### 3. Google Virtual Private Cloud

Google Virtual Private Cloud (VPC) provides networking capabilities for Google Cloud resources. It allows organizations to configure networks, subnets, IP addresses, routing, and network security.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service. It helps organizations deploy, manage and scale containerized applications.

## Three Advantages

1. Strong AI and Machine Learning capabilities - Google Cloud provides many tools and services for developing AI and Machine Learning applications.
2. Kubernetes expertise - Google created Kubernetes and provides GKE for managing containerized applications.
3. Data analytics - Google Cloud provides powerful services for processing and analyzing large amounts of data.

## Typical Enterprise Use Cases

Google Cloud can be used by enterprises for:
* Artificial Intelligence and Machine Learning
* Data analytics
* Big data processing
* Containerized applications
* Kubernetes deployments
* Web and mobile applications
* Application development
* Data storage and backup
* Global cloud applications
