# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Cloud Platform: AWS

A startup company should consider **Amazon Web Services (AWS)** because it offers a wide range of cloud services and flexible options for different budgets. AWS allows the company to start with a small amount of computing resources and increase them as the mobile application grows. This can help the startup avoid purchasing expensive physical servers at the beginning. AWS also provides many services that can support application development, databases, storage, and mobile applications.

### Recommended Services

* **Amazon EC2** – For running application servers.
* **Amazon S3** – For storing application files, images, and other data.
* **Amazon RDS** – For managing a relational database.
* **AWS Lambda** – For running application functions without managing servers.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make cloud migration easier to manage. The university can connect its existing infrastructure with Azure and gradually move selected services to the cloud. This approach can reduce disruption while allowing the university to use cloud-based resources.

### Recommended Services

* **Azure Virtual Machines** – For running Windows Server workloads.
* **Microsoft Entra ID** – For identity and access management.
* **Azure Virtual Network** – For creating and connecting private cloud networks.
* **Azure Blob Storage** – For storing documents, backups, and other data.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is a strong choice for an AI research company because of its Artificial Intelligence, Machine Learning, data analytics, and high-performance computing capabilities. Google Cloud provides specialized tools and infrastructure that can support demanding AI and ML workloads. The company can use cloud computing resources to train and run models without having to purchase and maintain all the required hardware. GCP also provides services that can help researchers process and analyze large datasets.

### Recommended Services

* **Google Compute Engine** – For high-performance computing workloads.
* **Vertex AI** – For developing, training, and deploying AI and Machine Learning models.
* **Google Cloud Storage** – For storing datasets and model files.
* **Google Kubernetes Engine (GKE)** – For deploying and managing containerized AI applications.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

AWS is a suitable choice for a global e-commerce company because it provides a large global infrastructure and services designed for highly available and scalable applications. The company can deploy its application across multiple geographic regions to serve customers around the world. AWS can also automatically increase or decrease computing resources based on customer demand. This can help maintain application performance during periods of high traffic.

### Recommended Services

* **Amazon EC2** – For running the e-commerce application.
* **Elastic Load Balancing** – For distributing traffic across application servers.
* **Amazon EC2 Auto Scaling** – For automatically adjusting computing capacity.
* **Amazon S3** – For storing product images, files, and other objects.
* **Amazon RDS** – For managing the e-commerce database.
