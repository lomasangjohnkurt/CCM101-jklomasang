After completing axtivity, I learned more about the three major cloud platforms, Amazon Web Services (AWS), Microsoft Azure and Google Cloud Platform (GCP). Among the three platforms AWS impressed me the most because it provides a wide range of services that can support different types of applications and organizations. I also learned that AWS can provide scalable resources, which is useful for businesses that may grow in the future.

AWS, Azure, and GCP have many similarities. All three platforms provide cloud computing services such as virtual machines, object storage, networking, databases, identity management, and security. They also provide tools for application development, monitoring, data analytics, and Artificial Intelligence. Although their services have similar purposes, each provider has different names, features, pricing options, and strengths. Business requirements are very important when selecting a cloud platform. A company should consider its budget, existing technology, application requirements, security needs, location of users and expected growth. like a Azure is a good choice for an organization that already uses Microsoft technologies, while GCP is a strong choice for AI and Machine Learning projects. AWS can be a good option when an organization needs many different cloud services and scalability.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. A cloud solution should be matched to the specific needs and goals of the client. I learned how to compare services and make recommendations based on business requirements. and also this mission improved my GitHub Cloud Computing Portfolio because I added organized research about AWS, Azure, and GCP. I also practiced creating Markdown documentation, comparison tables, decision matrices, and technical recommendations. This activity helped me develop better research, documentation, and cloud decision-making skills.
