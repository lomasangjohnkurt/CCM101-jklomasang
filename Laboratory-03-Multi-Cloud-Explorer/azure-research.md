# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, security, Artificial Intelligence, and application development. Azure is especially useful for organizations that already use Microsoft technologies.

## Global Infrastructure

Microsoft Azure has a global infrastructure consisting of Regions and Availability Zones. Azure Regions are geographic areas that contain cloud datacenters. Availability Zones are physically separate locations within supported regions that help protect applications from datacenter failures.

## Cloud Management Console

The Azure Portal is a web-based management interface for Azure services. Users can create and manage virtual machines, storage accounts, networks, databases, identities, and other cloud resources using the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers in the cloud. Organizations can use them to run applications, websites and workloads using Windows or Linux operating systems.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed to store large amounts of unstructured data. It can store files such as documents, images, videos, backups and other data.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks in Azure. It provides networking features such as subnets, IP addresses, routing and network security.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, applications, authentication and access to resources.

## Three Advantages

1. Strong Microsoft integration - Azure works well with Windows Server, Microsoft 365, Active Directory and other Microsoft technologies.
2. Enterprise support - Azure provides services designed for businesses and organizations with large IT environments.
3. Hybrid cloud capabilities - Azure supports connecting on-premises infrastructure with cloud services.

## Typical Enterprise Use Cases

Azure can be used by enterprises for:
* Hosting business applications
* Running Windows Server workloads
* Cloud storage and backup
* Database management
* Microsoft 365 integration
* Hybrid cloud infrastructure
* Application development
* Artificial Intelligence and Machine Learning
* Virtual desktop infrastructure
