
# Final Reflection

Throughout Missions 1 to 10, I developed my
knowledge and practical skills in Cloud Computing.

I learned how to use Linux commands, manage
servers, configure networking, deploy Docker
containers, and automate infrastructure tasks.

In Mission 10, I applied these skills by
designing and deploying my own cloud
infrastructure using Ubuntu Server, Docker,
Nextcloud, and MariaDB.

I also learned the importance of security,
persistent storage, firewall configuration,
and automated backups.

This experience helped me understand the
responsibilities of an Enterprise Cloud Architect
and improved my confidence in managing
cloud infrastructure independently.
