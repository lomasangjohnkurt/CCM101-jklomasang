# Mission Reflection

## Checkpoint 7 – Mission Reflection

This activity today is helped me to understand why monitoring and observability are important in cloud operations. It is not enough for containers or applications to be running successfully because the underlying host server can still experience resource problems.

First, checking the host server's resources is important even when containers are running perfectly because containers still depend on the resources of the host machine. If the server has very little available memory or disk space, applications may become slow, stop working, or crash. Monitoring RAM, disk capacity, CPU usage, and running processes provides a baseline that can be used to determine whether the server can handle additional workload. This is especially important when a website is expected to receive a large amount of traffic.

Second, the `docker logs` command can help troubleshoot a user who cannot log into a web application. The command displays the logs generated by the container, which may contain HTTP requests, errors, warnings, or other useful information. By examining the logs, an administrator can determine whether login requests are reaching the application and whether an error occurred while processing the request. This makes troubleshooting more systematic because the administrator can use actual evidence instead of simply guessing the problem.

And also monitoring logs and monitoring metrics are different but complementary. Logs provide detailed records of events that happened inside an application, such as successful requests and errors. Metrics provide numerical measurements of system performance, such as CPU usage, memory usage, and network activity. Logs can help explain **what happened**, while metrics help show **how the system is performing**.

This activity taught me that Cloud Operations Engineers need both logs and metrics to maintain reliable applications. Monitoring these resources regularly can help identify problems early and keep cloud services available and responsive.
