# Automation Research

## 1. Bash Script

It helps system administrators perform repetitive tasks faster and reduces the need to type each command manually.
A Bash script is a text file that contains Linux commands that run automatically in sequence. 

## 2. Variables

Variables store information, such as directory paths, filenames, and dates, so they can be reused throughout a script. Using variables
makes scripts easier to maintain because we can update a value in one place instead of changing it in multiple commands.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at specified times or intervals and 
It is important in cloud operations because it can automate tasks such as backups, log cleanup, system maintenance and monitoring.
