# Reflection

In this Laboratory Activities 1 to 9 I learned that cloud computing encompasses not only the creation and maintenance of virtual
machines but also infrastructure management, software deployment, data storage, services monitoring, system protection and automation
of repetitive actions. Every lab allowed me to understand the role of a cloud engineer.

Automation is necessary in working with hundreds of cloud servers since performing all actions manually consumes too much time and 
allows human errors. Using bash scripts and cron helps to carry out regular tasks efficiently. For instance the script for a backup 
I created will compress the application data automatically whereas the cron will schedule it to run daily.

This automation is dangerous because a destructive command or wrong file path may delete the critical data on hundreds
or thousands of servers if the script is executed without any tests beforehand. Therefore to avoid such mistakes an engineer should 
examine his/her script, conduct tests in a secure environment, keep backups, use proper permissions and check the results of its execution.
