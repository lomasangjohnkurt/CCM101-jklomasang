# Reflection

In my opinion, compute resources are one of the most important components in cloud infrastructure as they provide the processing power to operate applications and services. However, without sufficient compute resources, applications can become too slow or unable to process the workload. But at the same time the compute component is highly dependent on storage, networking and the operating system as well. Linux provides the cloud computing industry with a powerful and stable operating system for servers. Command-line tools in Linux are used to examine system resources, manage files, configure services, monitor systems and automate administrative tasks. I had an opportunity to practice those abilities through the KillerCoda activity.

New skills include the ability to explore a Linux cloud server using commands like `lscpu`, `free`, `df`, `findmnt`, `hostname`, `hostname -I`. Moreover, I had the opportunity to understand the compute, storage, networking and operating system resources as well as to identify the equivalent services of Amazon Web Services, Microsoft Azure and Google Cloud Platform. The GitHub portfolio became even more organized and helpful to keep the evidence of my cloud computing activities. The Laboratory 2 added to my portfolio the infrastructure investigation the cloud provider comparison, technical documentation and architecture planning. Through this mission, I had an opportunity to gain additional knowledge about cloud infrastructure components and their interrelation. I understood that cloud engineering is not just about the operation of servers.
