## Cloud Infrastructure Components

The major cloud infrastructure components investigated in this activity are compute, storage, networking, and operating systems.

### Compute Resources

Compute resources provide the processing capability required to run applications, services, and workloads. In a cloud environment, compute resources may be provided through virtual machines, containers, or other computing services.

### Storage Resources

Storage resources provide space for operating systems, applications, databases, and user data. Cloud providers offer different storage services depending on performance, capacity, durability and access requirements.

### Networking Resources

Networking resources allow cloud services, applications, users and devices to communicate. These resources include networks, IP addresses, routing and other networking services.

### Operating System

The operating system manages hardware and software resources and provides the environment where applications and services operate. Linux is widely used in cloud environments because of its flexibility, stability, and strong command-line tools.
