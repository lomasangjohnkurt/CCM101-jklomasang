# Security Audit Report

### 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege it means giving applications, users and services only the permissions they need to perform their tasks. 
Its important in cloud environments because it reduces the risk of unauthorized access, accidental changes and data breaches if an
account or service is compromised.

### 2. Attack Surface

Reducing unnecessary entry points helps make the server more secure.
These entry points may include open network ports, running services, exposed applications and accounts with weak security.

### 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This approach is safer than trying to 
block individual attackers because unknown or unauthorized connections are blocked automatically, reducing the number of ways
an attacker can reach the server.
